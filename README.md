# 🧟 Zombie Survival

A 2D survival game built with Python and Pygame.

## 🎮 About
Fight waves of zombies and bosses in this action-packed 2D game.

## 🚀 How to Run
1. Install Python
2. Install Pygame: `pip install pygame`
3. Run: `python main.py`
